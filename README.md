# Teacups UI

Teacups UI contains small, framework-specific building blocks for applications built with the Okisioli.Teacups libraries, keeping shared UI contracts separate from WPF and Avalonia implementation details.

## Packages

- **Core** — framework-neutral UI abstractions, including dialog contracts.
- **Core.WPF** — WPF implementations of Core abstractions.
- **Core.Avalonia** — Avalonia implementations of Core abstractions.

For a practical dialog example, see the future GitHub Wiki [Dialog Service](docs/wiki/Dialog-Service.md) page draft. When the repository Wiki is enabled, that page will live in the separate Wiki repository as `Dialog-Service.md`.
